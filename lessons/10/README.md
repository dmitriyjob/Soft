# №10 · IP-адреса и маски

Презентация по предоставленному скринкасту `2026-11-12 15-07-46.mp4`. Сохранены исходные оформление, тексты, иллюстрации, нумерация 26 слайдов и 122 показанных состояния.

Открыть: https://dmitriyjob.github.io/Soft/lessons/10/

## Как устроена копия

Визуальная основа — кадры и анимация самой записи. В `media/` находятся кадры WebP без дополнительного сжатия и локальный MP4 с вырезанной областью презентации. Браузерная панель и рабочий стол удалены. Переход вперёд воспроизводит соответствующий фрагмент анимации и останавливается на следующем состоянии. Нумерация и исходные секунды хранятся в `reference.js`.

Поверх кадров работают HTML-элементы: навигация, содержание, пояснения, переключатели байта, ввод числа 0–255, перетаскивание границы сети, изменение маски, IPv4-калькулятор, ползунок количества нулей, кнопки Run и тест с результатами. При изменении значения соответствующая область кадра заменяется живым элементом. Проверки IPv4, маски, адресов сети и broadcast выполняются на JavaScript. Вывод Run вычисляется для четырёх показанных примеров; произвольный интерпретатор Python не подключён.

Это покадровая реконструкция предоставленной записи, а не исходный код сайта. Состояния, которых нет в скринкасте, не домысливались: например, на слайде 25 показан только заголовок «Алгоритм №10». Текстовые пояснения составлены по показанным примерам и доступны через нижнюю панель и клавишу N.

## Управление

- Кнопки нижней панели, стрелки ← →, пробел, щелчок по свободной области слайда.
- M — содержание, N — пояснения, F — полный экран, ? — справка.
- Home / End — первый / последний слайд, Esc — закрыть панель.
- Ссылки вида `#14.2` открывают отдельное состояние.
- На узких экранах панель управления сохраняет размер кнопок, содержимое слайда масштабируется целиком.
- При `prefers-reduced-motion: reduce` используются неподвижные кадры.

Страница статическая, без сборки и внешних запросов. Шрифты Inter и JetBrains Mono включены локально вместе с лицензиями OFL. Все зависимости для просмотра находятся в этой папке; исходный MP4 со скринкастом не требуется.

## Обновление медиа

Из исходного видео выделена область `crop=1920:960:0:36`, кодек H.264, CRF 17, без звука, `-movflags +faststart`. Для каждого состояния кадр извлекается непосредственно из исходного видео на секунде `posterTime` из `reference.js` с тем же кадрированием, кодек WebP в режиме lossless с явным преобразованием `format=rgb24` → `bgra`, сохраняющим RGB-пиксели кадра. Неподвижные кадры также служат резервным отображением, если браузер не может воспроизвести MP4.
