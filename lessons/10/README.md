# Задание 10 · IP-адресация

Интерактивная HTML-презентация по предоставленному скринкасту `2026-11-12 15-07-46.mp4`: 26 основных слайдов с последовательными шагами и плавными переходами. Оформление согласовано с остальными уроками репозитория.

Открыть после публикации: https://dmitriyjob.github.io/Soft/lessons/10/

Содержание:

- Почтовая аналогия, доставка пакетов и адрес отправителя.
- IPv4: 32 бита, четыре октета, двоичная запись и ведущие нули.
- Сеть и узел, граница сети, маска, побитовое И и адрес сети.
- Разборы задач на восстановление маски, разные сети, число адресов и наибольший адрес компьютера.
- Сетевой калькулятор, четыре примера с `ipaddress`, тест из шести вопросов, алгоритм решения и шпаргалка.

Интерактивы: сборка байта переключением битов; изменение префикса ползунком или щелчком по биту; визуализация количества адресов; калькулятор IPv4 с проверкой ввода; тест с обратной связью. Вывод примеров Python вычисляется в браузере для показанных данных; интерпретатор Python не подключён. Для /31 и /32 калькулятор отдельно отмечает, что обычное правило «минус два адреса» неприменимо.

Управление: кнопки «Далее» и «←», клавиши со стрелками, пробел или щелчок по слайду. Кнопка слева открывает содержание. Ссылки `#14.2` открывают конкретный шаг. На телефоне слайды прокручиваются вертикально, длинные двоичные таблицы — горизонтально. Настройка `prefers-reduced-motion` отключает анимации.

Текст и схемы редактируются в `lesson.js` и `style.css`; исходное видео для работы презентации не требуется. Страница открывается статически, сборка и внешние библиотеки не нужны.
