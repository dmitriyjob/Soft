Протягиваем на все строки

Знак $ и вторая ВПР

Без $: Магазин.A2:C19 → A3:C20 → A4:C21…
диапазон уезжает вниз → #Н/Д

С $: $Магазин.$A$2:$C$19 — стоит на месте

LibreOffice: Shift + F4  ·  Excel: F4

Двойной щелчок по уголку ячейки — формула протянется на все строки (4320).

Вторая ВПР — по артикулу в листе «Товар». Меняется только номер столбца:

A · 1B · 2C · 3D · 4E · 5F · 6

Фильтры и подсчёт

Фильтры → новый лист → СУММ

  • 1Выделяем столбцы по буквам → включаем автофильтр (воронка).
  • 2Ставим все условия: дата, район, товар, тип операции.
  • 3Даты «включительно» — границы оставляем.
  • 4Выделяем результат → копируем → новый лист (плюсик внизу).
  • 5Там считаем =СУММ(…). На листе с фильтром не считаем — СУММ видит и скрытые строки.

  • 1Разбери вопрос по кусочкам: какие поля и из каких таблиц нужны.
