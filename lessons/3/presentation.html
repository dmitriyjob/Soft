Что такое база данных?

Запись = строка Поле = столбец Значение = ячейка
Да, простейшая. Но обычно база данных — это несколько таблиц, связанных ключами. Как в задании №3: три листа, которые ссылаются друг на друга.

Всё в одной таблице

магазин M1 магазин M3 товар 1 товар 22 0 повторов
Лишний объём: адрес и название товара переписаны в каждой строке — а строк тысячи.
Ошибки: магазин переехал — исправь сотни строк. Пропустишь одну — база сама себе противоречит.

Разделяем: каждый факт — один раз

Чтобы каждый факт хранился один раз: адрес магазина — только в «Магазине», название товара — только в «Товаре». В «Движении» остаются короткие ссылки — ID магазина и артикул.

Связь по ID магазина

Поле, по которому строку можно найти однозначно. В «Магазине» M1 встречается ровно один раз — поэтому по M1 из «Движения» всегда понятно, о каком магазине речь.

Связь по артикулу

Название длинное, в нём легко опечататься, и у разных товаров оно может совпадать. Артикул — короткий и уникальный. Идеальный ключ.

Как ищет компьютер

Ключа нет в первом столбце: опечатка, лишний пробел, не тот лист — или диапазон начинается не со столбца с ключом.

Зачем знак $?

Без $: A2:C19 → A3:C20 → …
→ #Н/Д
С $: $A$2:$C$19 — на месте

Вторая ВПР: товар

Меняется только номер столбца
ВПР ищет только в первом столбце диапазона. Поэтому диапазон начинаем со столбца с ключом: $Товар.$A:$F, где A — артикул.

Фильтры: оставляем только нужное

Границы входят: берём и 2, и 9 августа. Потеряешь крайнюю дату — ответ будет неверным.
Столбец «Тип операции»

Что считать: поступление или продажа?

«Сколько поступило?»
Σ Поступление
0
«Сколько продали?»
Σ Продажа
0
«На сколько изменилось?»
Поступление − Продажа
0
Тогда наоборот: продажа − поступление. Смысл тот же — сравниваем, сколько ушло и сколько пришло.

На листе с фильтром не считаем

=СУММ(E2:E4321) → … ✗
=СУММ(E2:E13) → 3 000 ✓
Можно: =ПРОМЕЖУТОЧНЫЕ.ИТОГИ(9; E2:E4321) складывает только видимые строки. Но копия на новый лист проще и её легко проверить глазами.

Считаем ответ

3 000−911= ?
Ответ: 2089 ✓
3 000 — сколько поступило. А спрашивают, на сколько увеличилось: вычитаем проданное.
