# Задание 4. Кодирование и условие Фано

Презентация из 26 слайдов по материалам [урока Иона](https://infa-ion2.ru/lessons/4/). Слайды, стили, интерактивные задания и пояснения находятся в этой папке.

Открыть урок можно по адресу `/Soft/lessons/4/#1`. Ссылки вида `#12.3` ведут на конкретный шаг. Кнопка «Все уроки» открывает каталог Soft.

- Стрелки переключают шаги и слайды. На сенсорном экране можно листать свайпом.
- Клавиша G открывает оглавление, N — пояснения, Q — вопрос к слайду. Клавиша ? показывает остальные команды.
- На слайде 8 можно проверить свой набор кодов, на слайде 18 — построить дерево, на слайде 24 — пройти тест.

Разметка слайдов находится в `index.html`, оформление — в `styles.css` и `fano.css`, управление и тренажёры — в `app.js`, пояснения — в `notes.js`.
