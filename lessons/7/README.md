# Задание 7 · Страница выбора частей

`index.html`, `hub.css` и `hub.js` показывают три части задания:

- `part-1/` — кодирование изображений, 11 слайдов.
- `part-2/` — кодирование звука, 14 слайдов.
- `part-3/` — передача данных, 3 слайда.

Части 1 и 3 используют общие `lesson.js` и `style.css`. Атрибут `data-lesson-part` выбирает нужные слайды. Часть 2 использует исходники из `../7.2/`; прежний адрес `/lessons/7.2/` продолжает работать.

`progress.js` сохраняет номер слайда и шага каждой части в `localStorage` под ключом `soft-lesson7-progress-v1`. Ссылка с `?resume=1` восстанавливает сохранённый шаг. «С начала» открывает первый слайд без восстановления. При недоступном хранилище презентации и страница выбора остаются доступны.

`presentation.html` сохраняет исходную презентацию по графике целиком. Старые ссылки вида `/lessons/7/#10` перенаправляются на соответствующий слайд в ней.

При изменении общих JS/CSS обновляйте версии `?v=` во всех использующих их HTML-оболочках, включая `part-1/`, `part-2/`, `part-3/`, `presentation.html` и `../7.2/index.html`. Если меняется число слайдов или положение шпаргалок, обновляйте ссылки и `data-max` в `index.html`.
