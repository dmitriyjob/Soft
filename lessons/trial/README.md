# Пробное занятие

https://dmitriyjob.github.io/Soft/lessons/trial/

Основа — предоставленная презентация «ПРОБНОЕ.pptx.pdf». Все 64 страницы сохранены в 40 основных слайдах: шесть тактов тренировки, три этапа двоичного перевода и восемнадцать состояний разбора объединены в последовательности внутри соответствующих слайдов.

- Щелчок по слайду, →, пробел, Enter — следующий шаг.
- ← — предыдущий шаг; на первом шаге — предыдущий слайд с завершённым разбором.
- Кнопка ↺ повторяет текущий слайд.
- В машине Тьюринга можно включить проигрывание и поставить его на паузу.
- F или ⛶ — полный экран. Слева — содержание; Escape закрывает его.
- На телефоне для чтения таблиц удобнее альбомная ориентация.

Оригинальное оформление и начертания шрифтов сохранены в изображениях WebP, отрисованных из PDF с удвоенным разрешением. Отдельные карточки экспортированы в слои и появляются последовательно. В машине Тьюринга головка вынесена в отдельный слой и плавно перемещается. Текст каждого состояния доступен в скрытом текстовом описании.

`slides.json` задаёт порядок слайдов, изображения, слои и состояния. `source/build_assets.py` воспроизводит экспорт из исходного PDF (нужны PyMuPDF и Pillow):

```
python source/build_assets.py /path/to/ПРОБНОЕ.pptx.pdf
```

Запуск локально: `python -m http.server 8000` из корня репозитория, затем `/lessons/trial/`. Файл JSON загружается через HTTP. Внешние шрифты, скрипты и сервисы не используются.
